=====================================================
BACKGROUND MUSIC DIRECTORY
=====================================================

Place your background music MP3 file in this folder and name it:
background-music.mp3

How it works:
- As soon as someone opens the website (or interacts/clicks anywhere), it will automatically play at 60% volume!
- The website includes a cute floating Mute/Unmute button in the corner with music notes and volume control.
- Supported audio format: .mp3 (or .wav / .m4a).
